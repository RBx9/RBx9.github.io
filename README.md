# RBx9 Repo

![RBx9 Repo logo](assets/rbx9-logo.jpg)

A reusable Sileo / APT repository for jailbreak tweaks developed by **RBx9**. Current DuoBar editions: **RootHide v0.2.5** (tested, hotspot and Control Center fixes) and **Rootless v0.2.3** (separate initial build).

**Sileo source URL:**
https://rbx9.github.io/

## Install in Sileo
1. Open Sileo → Sources → +.
2. Paste `https://rbx9.github.io/`.
3. Refresh sources, choose **RBx9 Repo**, and install a compatible package.




This is a personal repository, **not affiliated with Sileo or RootHide**.
